# news-image-01 — Friday 13 November 2026 in one image

Entry for make.fun bounty "Sum up 13 November's world news in one image".

The program (`main.ts`, Node 22, standard library only) copies `entry.png`
to `/output/entry.png`. The image is a newspaper front page for Friday
13 November 2026: masthead "WORLD NEWS" with the date, and four illustrated
panels — NVIDIA CEO RESIGNS, US FLIGHTS HALTED, MICROSOFT OUTAGE, and
EUROPE JOINS UKRAINE TALKS. It was generated for this entry; the stories
were researched from live reporting of that day (see `../RESEARCH.md`).

The image is a JPEG in a file named `entry.png`, which the rules allow
(the format is told apart by its first bytes). 1024×1024 px, under 1 MiB.
